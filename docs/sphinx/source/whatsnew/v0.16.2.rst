v0.16.2 (Anticipated December, 2026)
------------------------------------

Breaking Changes
~~~~~~~~~~~~~~~~


Deprecations
~~~~~~~~~~~~


Bug fixes
~~~~~~~~~
* :py:func:`pvlib.tracking.calc_surface_orientation` returns scalar when input
  is scalar (:issue:`2881`, :pull:`2882`)
* :py:func:`pvlib.irradiance.dirint` now returns 0 instead of NaN for
  ``solar_zenith`` greater than ``max_zenith`` when the airmass is
  undefined, and uses the dew point unavailable coefficients for NaN
  values of ``temp_dew``, as documented. (:issue:`2900`)

Enhancements
~~~~~~~~~~~~
* Add ``dataset`` parameter to :py:func:`~pvlib.iotools.get_era5`
  allowing for choosing between ERA5 and ERA5-Land datasets.
  (:pull:`2780`)

Documentation
~~~~~~~~~~~~~
* Clarified in :py:func:`pvlib.tracking.singleaxis` that the tracker
  rotation minimizes the angle of incidence (AOI) to maximize the use of
  direct normal irradiance (DNI). (:issue:`2314`, :pull:`2869`)
* Fix the :py:func:`pvlib.spa.solar_position` docstring, which listed
  outputs ``elevation`` and ``apparent_elevation`` in the wrong order.
  (:issue:`2886`, :pull:`2887`)
